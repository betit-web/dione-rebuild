# Dione Rebuild — launcher

**Projet de fans non officiel, nécessite sa propre copie Steam du jeu.**

Recréation non commerciale de la carte Mt Dione de *Ring of Elysium* (moteur Godot 4). Aucun lien avec l'éditeur ou le développeur du jeu.

## Télécharger

**[DioneLauncher.exe](https://github.com/betit-web/dione-rebuild/releases/latest/download/DioneLauncher.exe)** — Windows 10/11 64 bits, ~130 Ko.

## Communauté

Discord : https://discord.gg/BJjg4VJUy

## Il te faut

- **Ring of Elysium installé dans ta bibliothèque Steam.** Aucun fichier du jeu n'est distribué ici : les données sont extraites sur ton PC depuis ta propre copie (lecture seule, rien n'y est modifié).
- Environ 6 Go libres.

## Ce que fait le launcher

1. Crée ton compte (email + mot de passe, vérification par email).
2. Trouve Ring of Elysium dans Steam et vérifie sa version.
3. Télécharge notre code et les moteurs nécessaires (Godot, Python), tous vérifiés par SHA-256.
4. Extrait les données du jeu en local (10 à 20 min la première fois).
5. JOUER ouvre le menu, connecté à ton compte (ton identifiant d'ami = ton compte).

Les mises à jour sont automatiques.

L'exe n'est pas signé : Windows SmartScreen peut afficher un avertissement → « Informations complémentaires » → « Exécuter quand même ».
